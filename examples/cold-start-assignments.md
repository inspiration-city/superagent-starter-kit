# Cold-start Assignments

Use these to dogfood a newly connected agent. Each assignment should begin with the full first-run ritual.

## 1. Workspace orientation

Produce a short report describing the room, current assignments, major workspace areas, and three useful live skills. Read-only.

## 2. File-management proof

In the room sandbox, create a small page, inspect its metadata, read a line range, copy it under a new name, move the copy to another approved parent, trash one disposable page, list the trash, restore it, and then clean up. Ask before each destructive phase.

## 3. Build a report

Create a report page that lists recently modified pages under an approved folder. Read `local.skills.report`, find a nearby example, build the smallest version, and verify it with `@snapshot`.

## 4. Create a reusable workspace tool

Given a narrowly specified need, inspect live `local.tools.*` examples and determine whether existing tools compose the result. Build only if a new tool is still justified, test it in the sandbox, and document its live skill dependencies.

# Building in IC

Before building anything, inspect the live tool catalog, search for nearby examples, and read the relevant live skill.

- **Pages:** use narrow locations and surgical writes. Snapshot composed pages after editing.
- **Reports:** load `local.skills.report`; prefer an existing report/template primitive.
- **Tools:** inspect `local.tools.<name>` examples. A tool is agent-facing intent and its page owns instructions, hook, and executable script.
- **Skills:** inspect the live skills catalog and skill-creation guidance. Link evolving tool details instead of copying catalogs.
- **Agents:** inspect existing `city.agent.*` pages and live agent-creation instructions before defining identity or skills.
- **Workflows:** keep file movement, assignment state, and substantive page content as separate concerns.

For every artifact: make the smallest useful version, test in the room sandbox or a designated disposable page, then verify both stored source and rendered result.
